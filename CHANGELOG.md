# Changelog

Notable project changes are recorded here. This file is for implemented and documented changes, not a plan of future work.

## [0.1.0] — 2026-10-24

- Added initial Next.js App Router + TypeScript project structure.
- Added direct surah browser with local search and revelation-type filter.
- Added reader route with Arabic text and Indonesian/English translation selection.
- Added local bookmarks and last-read state.
- Added server route to resolve per-ayah audio URLs.
- Added light/dark theme tokens and responsive CSS.
- Added Gus AI preview panel; no model API is connected.
- Consolidated the design-token source of truth and included the Stitch export as a reference.
- Added first-pass product requirements, architecture decisions, API integration note, QA plan, and deployment guide.

Note: Dependency installation and build validation have not yet been run in this environment. This is an initial scaffold, not a release-ready claim.
